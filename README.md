# R-Bases-De-Datos

Repositorio de ejercicios, apuntes y ejemplos practicos para el aprendizaje de bases de datos relacionales y no relacionales.

## Introduccion

Este proyecto organiza contenidos de base de datos en bloques tematicos progresivos: desde fundamentos del modelo relacional y consultas SQL, hasta tratamiento de datos, modelado entidad-relacion y uso de MongoDB.

El repositorio combina teoria aplicada y practica con ejemplos en distintos formatos SQL, Python, PHP, HTML, JSON y diagramas.

## Estructura principal

- `001-Almacenamiento de la información`: contenidos introductorios sobre almacenamiento de datos.
- `002-Bases de datos relacionales`: fundamentos del modelo relacional, tipos de datos, claves, restricciones, indices, vistas y usuarios.
- `003-Realización de consultas`: consultas SQL desde operaciones basicas hasta agrupamientos y composiciones internas/externas.
- `004-Tratamiento de datos`: insercion, borrado, modificacion, integridad, transacciones y concurrencia.
- `005-Programación de bases de datos`: carpeta reservada para contenidos de programacion aplicada a BBDD.
- `006-Interpretación de Diagramas EntidadRelación`: modelado ER, generalizacion/especializacion y paso al modelo relacional.
- `007-Uso de bases de datos no relacionales`: introduccion a NoSQL y tipos de bases de datos no relacionales.

## Tipos de recursos incluidos

En el repositorio encontraras, principalmente:

- Scripts SQL `.sql` para creacion de bases de datos, tablas y consultas.
- Documentacion `.md` con explicaciones de cada bloque.
- Ejemplos con Python `.py` y PHP `.php`.
- Material visual y estructural `.html`, `.svg`, `.json` para diagramas y representaciones ER.

## Objetivo del repositorio

- Practicar consultas y operaciones SQL CRUD, filtros, resumenes y agrupamientos.
- Comprender y aplicar integridad referencial, claves y restricciones.
- Diseñar modelos de datos mediante diagramas entidad-relacion.
- Relacionar el modelo conceptual con su implementacion en bases de datos reales.
- Introducir el trabajo con bases de datos no relacionales como MongoDB.

## Requisitos recomendados

Para aprovechar los ejercicios se recomienda contar con:

- Un motor SQL.
- Cliente de administracion de base de datos Workbench, DBeaver, phpMyAdmin, etc..
- Python 3 y/o PHP para ejecutar ejemplos de integracion.
- MongoDB.

## Forma de uso sugerida

1. Recorre las carpetas en orden numerico `001` -> `007`.
2. Lee primero los archivos `README.md` de cada subtema.
3. Ejecuta los scripts `.sql` en tu gestor de bases de datos.
4. Prueba los ejemplos en Python/PHP cuando aparezcan en cada bloque.
5. Usa los recursos visuales `.svg`, `.html`, `.json` para reforzar el modelado ER.
